# StickyTodo 下载

圆角、可调透明度的 macOS 桌面待办。此仓库仅提供安装包和带签名的更新信息；源代码单独维护。

适用于 Apple Silicon（M 系列）Mac，macOS 13 或更新版本。

请从 Releases 下载 ZIP，解压后将 StickyTodo.app 放入应用程序文件夹再打开。0.7.0 起可在“三个点 → 更新”开启自动检查，安装前由你确认。0.5 / 0.6 需要先手动安装一次带更新功能的新版。已有任务和外观设置保留。

当前为未做 Apple 开发者签名和公证的测试版，首次安装兼容性仍需在其他 Mac 验证。若系统阻止打开，请反馈提示，不要关闭系统安全保护。

更新包与版本信息使用 Ed25519 签名；更新检查不会上传待办内容。
